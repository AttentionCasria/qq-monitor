# 🤖 从零开始的 QQ 群监控机器人搭建指南

从零开始的完整操作流程，每一步都给你标清楚，照着做就行！✨

---

## 🛠️ 一、准备工作

1. 💻 **一台 Windows 电脑**（Win10/Win11 都行）。
2. 👻 **一个备用 QQ 号**（建议用小号，避免大号被封风险）。
3. 📱 **手机 QQ 客户端**（用来扫码登录）。
4. 📦 **一个解压软件**（系统自带的就可以）。
5. 🐍 **Python 环境**（如果你要跑监控脚本的话，到时候我们会讲怎么装）。

---

## 📥 二、下载 NapCat

打开 NapCat 的官方下载页，你会看到一堆文件。**请认准这个名字：**

`NapCat.Shell.Windows.OneKey.zip`

- 🔹 大小只有 1MB 左右，它是一个引导程序，会自动下载所需组件。
- 🔹 点它下载，保存到桌面或任意一个**英文路径**的文件夹（⚠️别放中文名文件夹里）。

---

## 🚀 三、安装 & 第一次启动  

1. 把下载好的 `NapCat.Shell.Windows.OneKey.zip` **解压**到当前文件夹。
2. 进入解压出来的文件夹，找到 `NapCatInstaller.exe`，双击运行。
3. 会弹出一个黑色命令行窗口，它会自动检测环境并下载核心文件，**中间如果提示按任意键或输入 y，直接按回车即可**。
4. 下载完成后，它会在旁边自动生成一个新文件夹，名字类似 `NapCat.44498.Shell`。  
   *🎉 这步就是安装完成，以后我们用这个新文件夹。*

---

## 🔑 四、登录你的 QQ

1. 进入生成的文件夹，比如 `NapCat.44498.Shell`。
2. 找到 `napcat.bat` 文件，**双击它**。
3. 又会弹出一个黑色窗口，稍等几秒，窗口里会出现一个**二维码**（由字符组成的，能看清楚）。
4. 拿出手机 QQ，**扫一扫这个二维码**，在手机上点“确认登录”。
5. 如果窗口里最终显示“NapCat 启动成功”之类的字样，说明登录成功了。**这个窗口千万不能关**，一直开着就行。

> **⚠️ 可能遇到的问题**：
> - 窗口提示 “已登录”？  
>   说明之前登录的进程没退干净。双击运行文件夹里的 `napcat.kill.qq.bat` 清理一下，再重新双击 `napcat.bat` 就好了。
> - 扫码提示“环境异常”？  
>   换个网络（比如电脑连手机热��）再扫，多试几次一般能过。

---

## 🌐 五、进入 WebUI（后台管理）

NapCat 的运行状态和配置都需要在浏览器里操作。

1. 打开浏览器（Chrome、Edge 都行），在地址栏输入：
   ```text
   http://localhost:6099/webui/
   ```
2. 回车后就能看到一个管理界面。如果能看到 **“OneBot11”** 相关的配置项，就说明一切正常，你的 QQ 已经变成了可以被程序控制的“机器人” 🤖。

---

## 🔌 六、开启正向 WebSocket 服务（让 Python 能连上）

为了让 Python 脚本能收到 QQ 消息并自动回复，需要开一个“通道”。

1. 在 WebUI 左边菜单找到 **“网络配置”**（或者类似字眼）。
2. 找到 **“OneBot11”** 这一区域。
3. 点击 **“添加配置”**，选择 **“正向 WebSocket”** 或 **“WebSocket Service”**。
4. 填入以下内容：
   - **监听地址**：`127.0.0.1`
   - **监听端口**：`8080`（只要没被其他程序占用就行，后面代码会用到）
   - **Token**：**先空着**（如果你是新手，不要设置密码）
5. 点击 **“保存”** / **“启用”** 之类按钮，确认开关是**打开**状态（一般会变成粉色或绿色）。

> 💡 这一步总结：**你在 NapCat 里开了一个叫 8080 的“房间”，等着 Python 来敲门。**

---

## 🐍 七、编写 Python 监控脚本（示例）

你也可以直接复制下面的代码，比如监控群消息，当有人发“收”字时立刻弹窗提醒你。

### 1. 安装 Python（如果已装可跳过）
去 python.org 下载安装包，安装时**勾选 “Add python.exe to PATH”**，一路下一步就行。

### 2. 安装需要的库
打开“命令提示符”（Win+R 输入 cmd 回车），输入：
```bash
pip install websockets
```
回车等待安装完成。

### 3. 新建一个文本文件，改名成 `monitor.py`
里面粘贴以下代码（记得把群号改成你的，如果你想监控多个群，用逗号分隔）：

```python
import asyncio
import websockets
import json

# 配置
WS_URL = "ws://127.0.0.1:8080"          # 刚刚 NapCat 里开的端口
TARGET_GROUPS = [866065107]             # 你要监控的群号，改成你自己的

async def listen():
    async with websockets.connect(WS_URL) as ws:
        print("已连接到 NapCat，开始监控群消息...")
        while True:
            msg = await ws.recv()
            data = json.loads(msg)
            # 只处理群消息
            if data.get("message_type") == "group":
                group_id = data.get("group_id")
                raw_msg = data.get("raw_message", "")
                user_id = data.get("sender", {}).get("user_id")
                # 检测目标群
                if group_id in TARGET_GROUPS:
                    print(f"群 {group_id} 收到 {user_id} 的消息: {raw_msg}")
                    # 关键词匹配
                    if "收" in raw_msg:
                        print(f"！！！注意：群 {group_id} 有人发了‘收’相关消息！！！")
                        # 还能加上桌面弹窗（需要 Python 调用 win32api，可选）

asyncio.run(listen())
```

### 4. 运行脚本
回到命令提示符，`cd` 到脚本所在目录，输入：
```bash
python monitor.py
```
如果一切正常，会打印 `已连接到 NapCat，开始监控群消息...` 🎉。

2. 观察 Python 窗口，应该会打印出 **一条警告**。
3. 想要停止脚本，直接按 `Ctrl + C` 就行。

## 💡 九、日常使用须知

- 🛑 **NapCat 那个黑色窗口要一直开着**，不然机器人就会掉线。
- 🔄 每次重启电脑后，需要重新运行 `napcat.bat`，并确保 WebSocket 配置还在。
- 🔌 如果 Python 连不上，先去 WebUI 检查 8080 端口的正向 WS 是不是开启状态。
- 🔢 端口被占用？可以换成其他数字（比如 8090），**两边（NapCat 和 Python 代码）改成一致**即可。

## 🌟 十、进阶扩展（等你熟悉了再玩）

- 🔒 可以在 WebUI 里设置一个 **Token**，然后在 Python 连接时加上密码，增加安全性。
- 🌍 除了正向 WebSocket，还可以用 HTTP API，这样就可以用任何语言（Java、JS 等）控制机器人。
- 🧠 能接上你自己的 AI 模型，实现自动回复、RAG 知识库问答等。
