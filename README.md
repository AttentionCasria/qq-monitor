# 使用指南

## 🛠️ 第一阶段：获取与安装（准备电话机）

1.  **选对型号**：在 GitHub 下载 `NapCat.Shell.Windows.OneKey.zip`。
    * **小白理解**：这是“一键包”，自带安装程序，省去了你自己配置环境的麻烦。
2.  **解压安装**：将压缩包解压到**非中文路径**（例如 `D:\NapCat`）。
3.  **运行安装器**：双击 `NapCatInstaller.exe`。
    * 它会弹出一个黑窗口自动下载核心文件。
    * 完成后，文件夹里会多出一个叫 `NapCat.xxxx.Shell` 的文件夹。

---

## 🔑 第二阶段：启动与登录（接通号码）

1.  **进入运行目录**：双击进入新生成的 `NapCat.xxxx.Shell` 文件夹。
2.  **点火启动**：双击运行 **`napcat.bat`**。
3.  **扫码授权**：
    * 黑窗口会刷出一个二维码。
    * 用手机 QQ 扫码。登录成功后，黑窗口会开始滚动群聊消息日志。
    > **⚠️ 注意**：如果提示“账号已登录”，说明后台有残留进程。先关掉黑窗口，运行文件夹里的 **`napcat.kill.qq.bat`** 杀掉残留，再重新开 `napcat.bat`。

---

## 🌐 第三阶段：WebUI 配置（搭建桥梁）

这是最关键的一步，让你的 Python 脚本能连上 QQ。

1.  **进入管理后台**：在浏览器输入 `http://localhost:6099/webui/`。
2.  **开启通信接口**：
    * 点击左侧 **“网络配置”**。
    * 点击 **“新建”**，选择 **“正向 WebSocket”**（Websocket服务器）。
    * **设置参数**：
        * **主机**：`127.0.0.1`
        * **端口**：`8080`（必须和脚本里一致）。
    * **保存**：点击保存图标，确保那个开关是**开启（粉色/红色）**状态。

---

## 🐍 第四阶段：代码接入（让机器人上班）

1.  **配置脚本**：打开你的 Python 监控脚本（如 `monitor.py`）。
2.  **对齐暗号**：确保代码中的 `WS_URL` 写的是 `"ws://127.0.0.1:8080"`。
3.  **运行监控**：在 PyCharm 或终端运行脚本。
    * 看到 `已连接到 go-cqhttp，开始监控群消息...` 就说明大功告成了！

---

## 💡 常见问题排查表

| 现象 | 原因 | 解决方法 |
| :--- | :--- | :--- |
| **`ConnectionRefusedError`** | NapCat 没开，或 8080 端口没配好。 | 检查 WebUI 里的“正向 WebSocket”是否开启。 |
| **扫码后没反应** | 腾讯风控或网络问题。 | 尝试手机关掉 WiFi 换流量扫码。 |
| **搜不到群消息** | 群号填错了，或小号没进群。 | 检查脚本里 `TARGET_GROUPS` 的群号。 |
| **窗口一闪而过** | 路径有中文或缺少组件。 | 确保文件夹在英文路径下，尝试重新运行安装器。 |

---

### **最后的小提示**
* **黑窗口不能关**：`napcat.bat` 运行的黑窗口是机器人的“心脏”，关了它机器人就断网了。
* **监控关键词**：既然你已经在监控考研群了，可以多加几个关键词（比如“学硕”、“专硕”、“调剂”），用逗号隔开即可。
